How to publish it

  1. Tap Copy status.json above.
  2. Open status.json in your repository on GitHub and tap the pencil icon. Bookmark that page on your phone's home screen — it turns this into a three-tap job.
  3. Select everything, paste, and commit.

The site picks up the change within about five minutes on any page left open, and immediately on a fresh load.
